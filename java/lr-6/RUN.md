# ЛР 6: запуск і показ

Потрібен лише Docker (Maven і JDK 21 запускаються в контейнері). Усі команди з теки роботи (`java/lr-6` від кореня репозиторію).

## Пайплайн

```sh
cd java/lr-6
make build   # зібрати проєкт у target/
make run     # обидва файли в одному сховищі
make casts   # у клієнтському коді немає приведень типу
make check   # незалежна перевірка 40 рядків і 37 ключів
```

`make show` виконує все по черзі, `make help` показує цілі. Файли в репозиторії `make` не змінює: збірка йде в `target/`, вивід друкується в термінал.

## Кроки

- `make run`: клас `ua.duikt.lavrishko.lr6.Main` з `data/v2_issues.txt` і `data/v2_members.txt`. Одне `Storage<K, T extends Keyed<K>>` для `Issue` і `Member`, завантаження через `Loader` з `IssueParser` і `MemberParser`.
- `make casts`: `grep -rnE '\((Issue|Member)\)' src`, шукає приведення типу.
- `make check`: `wc -l` і `cut | sort -u | wc -l` по обох файлах даних.

## Що показати

1. `make run`, задачі: `рядків у файлі 40, записів у сховищі 37`, `Повтори ключа (лишається пізніший запис): 3`, `Пошук SHOP-106: ... 8 SP`, `Пошук SHOP-000: не знайдено`, сортування за story points, `Перевірка: у списку 37, у сховищі 37, список і сховище містять ті самі записи: так`. Записи з рівними значеннями лишилися, пізніший рядок замінив ранній.
2. `make run`, учасники: те саме сховище, `falcon14 ... закрито 60`, сортування за кількістю закритих задач, `Перевірка ... так`.
3. `make run`, захист: `iterator().remove(): java.lang.UnsupportedOperationException`, `all().clear(): java.lang.UnsupportedOperationException`, `очищення відсортованої копії: у копії 0, у сховищі 37`, `подання all() бачить нові записи сховища: було 37, стало 38`.
4. `make casts`: порожній вивід і `(код завершення grep: 1)`, приведень типу в `Main` немає.
5. `make check`: `40`, `37` для задач і `40`, `37` для учасників. Це ті самі числа, що дала програма.

## Звідки що береться

- `data/v2_issues.txt`, `data/v2_members.txt`: дані варіанта 2 з Classroom.
- `src/main/java/ua/duikt/lavrishko/lr6/`: код сховища, парсерів і компараторів.
- `../../tools/mvn.sh`, `../../tools/java.sh`: Maven і Java 21 у docker, том `duikt-m2` для кешу залежностей.
- `run.sh`: те саме, але зберігає вивід у `results/`.
