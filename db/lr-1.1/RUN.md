# ЛР 1.1: запуск і показ

Потрібен лише Docker. Усі команди з теки `homework/db/lr-1.1`. Окремого звіту в ЛР немає, звіт ПР 1.1 лежить у теці `pr-1.1`.

## Пайплайн

```sh
cd /home/skalse/job/duikt/course_3/students/lavrishko_vladyslav/homework/db/lr-1.1
make queries    # свіжа копія car_rental_defense і п'ять додаткових завдань
make t3         # свіжа копія і завдання 1-3 (кожне tN виконує й попередні)
```

## SQL по кроках

- `make t1`: `sql/01-create-table.sql`, нова таблиця `insurance_policies` зі зв'язком до `cars`.
- `make t2`: `sql/02-alter-update.sql`, `ALTER TABLE` і зміна даних.
- `make t3`: `sql/03-mass-update.sql`, масове підвищення ставки класу «Економ» («До» і «Після»).
- `make t4`: `sql/04-delete-cascade.sql`, видалення авто і каскад на поліси.
- `make t5`: `sql/05-join-select.sql`, вибірка із з'єднанням чотирьох таблиць.

Кожна ціль `tN` залежить від попередньої (завдання будуються одне на одному) і спершу пересоздає базу. `make show` те саме, що `make queries`, тобто `make t5`. `make help` показує всі цілі. Файл створює таблицю, тому `make queries` щоразу пересоздає копію `car_rental_defense`.

## Що показати

1. `make t1`, завдання 1. Нова таблиця `insurance_policies` з двома полісами `EP-100234` і `EP-100235`. Це створення таблиці зі зв'язком до `cars`.
2. Завдання 2. `ALTER TABLE cars ADD COLUMN color`, чотири авто з кольором (білий, білий, білий, чорний). Це зміна структури й наявних даних.
3. Завдання 3. Ставка класу «Економ» `800.00`, потім `880.00`. Одна команда `UPDATE` змінює ставку для всього класу.
4. Завдання 4. `policies_left 1`: видалення авто 2 каскадом прибрало його поліс.
5. Завдання 5. П'ять активних оренд, з'єднання чотирьох таблиць.

Код: `sql/` (SQL кожного завдання), `defense_queries.sql` (усі п'ять завдань разом, лишається як у звіті), база `car_rental_defense.sql`.

## Звідки що береться

`make` друкує кожну команду, наприклад `./mysql.sh -t -vvv --skip-comments car_rental_defense < sql/01-create-table.sql`; `-vvv` друкує кожен запит перед результатом. `mysql.sh` запускає клієнт `mysql` у контейнері `duikt-mysql`, `mysql-up.sh` піднімає цей контейнер.

- `car_rental_defense.sql`: копія бази ПР 1.1 під назвою `car_rental_defense`.

`tidy.sh` лише скорочує вивід `mysql -vvv`: коментар із файла друкується одним рядком, запит після `mysql>`.
