# Вимоги безпеки до елементів архітектури «Прокат автомобілів» (OWASP ASVS 5.0.0)

Повний перелік до звіту ЛР 2. Архітектура й реєстр загроз: ЛР 1 (`security/lr-1/model/architecture.md`, `threats.md`). Усі ID й рівні звірено з текстом ASVS 5.0.0 (травень 2025) скриптом; суть вимог викладено власними словами.

Як читати. ID `8.2.2` = розділ V8, підрозділ 8.2, вимога 2. Рівень L1 (мінімум, перший рубіж), L2 (для більшості застосунків), L3 (максимальний захист, глибина). Колонка «Загрози» містить загрози з ЛР 1, які вимога закриває; у дужках рівень ризику: В високий, С середній, Н низький.

Правило поділу. Обов'язкова: вимога L1 або вимога L2, що закриває загрозу високого ризику (T01, T02, T04, T05, T08, T11, T14, T15, T16, T18, T28). Рекомендована, етап 2: решта L2. Рекомендована, етап 3: L3. Правило авторське: ASVS обов'язковість не задає, рівень обирає організація.
