Безпечний варіант (після захисту):

# Нормальний пошук
$ curl -s -G http://localhost:8080/demo/safe/search --data-urlencode "brand=Toyota"
  HTTP 200
  | Toyota | Corolla | 2022 | 1200.00
  | Toyota | Camry | 2023 | 1800.00

# Той самий рядок: шукається бренд із такою назвою, збігів немає
$ curl -s -G http://localhost:8080/demo/safe/search --data-urlencode "brand=' OR '1'='1"
  HTTP 200
  (рядків немає)

# Той самий UNION: просто текст параметра
$ curl -s -G http://localhost:8080/demo/safe/search --data-urlencode "brand=' UNION SELECT login,password_hash,0,0 FROM users-- "
  HTTP 200
  (рядків немає)

# Одинарна лапка: звичайний порожній результат, без помилки
$ curl -s -G http://localhost:8080/demo/safe/search --data-urlencode "brand='"
  HTTP 200
  (рядків немає)

# Форма реєстрації: SQL-ін'єкція в полі login (allow-list [A-Za-z0-9_.-])
$ curl -s -X POST http://localhost:8080/register -d login=x\'\ OR\ \'1\'=\'1 -d firstName=Олена -d email=o@example.com -d password=Secret123 -d phone=+380501234567 -d birthDate=1998-04-12 
  HTTP 400
  login      Логін може містити лише латинські літери, цифри та символи _ . -

# Форма реєстрації: DROP TABLE у полі login
$ curl -s -X POST http://localhost:8080/register -d login=a\'\;\ DROP\ TABLE\ users\;-- -d firstName=Олена -d email=o@example.com -d password=Secret123 -d phone=+380501234567 -d birthDate=1998-04-12 
  HTTP 400
  login      Логін може містити лише латинські літери, цифри та символи _ . -
