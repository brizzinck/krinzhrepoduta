Переповнення і довжина:

# Вразлива реєстрація: логін 10 000 символів, поле БД VARCHAR(32). Результат: 500 і подробиці помилки
$ curl -s -X POST http://localhost:8080/demo/vuln/register -d login=<a x10000> ... | head -c 420
{"timestamp":"2026-11-03T15:45:44.138+00:00","status":500,"error":"Internal Server Error","exception":"org.springframework.dao.DataIntegrityViolationException","trace":"org.springframework.dao.DataIntegrityViolationException: StatementCallback; SQL [INSERT INTO users (login, first_name, email, password_hash, phone, birth_date) VALUES ('aaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaa ... [скорочено]
  HTTP 500

# Безпечна форма: логін 10 000 символів
$ curl -s -X POST http://localhost:8080/register -d login=aaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaa ... [скорочено, усього 10121 символів]
  HTTP 400
  login      Логін має містити від 5 до 32 символів

# Безпечна форма: тіло запиту ~5 МБ (ліміт 16 КБ)
  розмір тіла: 5000018 байтів
$ curl -s -X POST http://localhost:8080/register --data-binary @big.txt -H 'Content-Type: application/x-www-form-urlencoded'
{"error":"Тіло запиту завелике, максимум 16384 байтів"}
  HTTP 413

# Безпечний JSON-ендпоінт: так само 413
{"error":"Тіло запиту завелике, максимум 16384 байтів"}
  HTTP 413

# Chunked-запит без Content-Length: фільтр рахує прочитані байти, теж 413
$ curl -s -X POST http://localhost:8080/api/register -H 'Content-Type: application/json' -H 'Transfer-Encoding: chunked' --data-binary @big.json
{"error":"Тіло запиту завелике, максимум 16384 байтів"}
  HTTP 413
$ curl -s -X POST http://localhost:8080/register -H 'Transfer-Encoding: chunked' --data-binary @big.txt -H 'Content-Type: application/x-www-form-urlencoded'
{"error":"Тіло запиту завелике, максимум 16384 байтів"}
  HTTP 413

Неправильні типи й формати:

# birthDate=abc
$ curl -s -X POST http://localhost:8080/register -d login=client01 -d firstName=Олена -d email=o@example.com -d password=Secret123 -d phone=+380501234567 -d birthDate=abc 
  HTTP 400
  birthDate  Некоректна дата: використовуйте формат РРРР-ММ-ДД і існуючу календарну дату

# birthDate=2099-01-01 (майбутнє)
$ curl -s -X POST http://localhost:8080/register -d login=client01 -d firstName=Олена -d email=o@example.com -d password=Secret123 -d phone=+380501234567 -d birthDate=2099-01-01 
  HTTP 400
  birthDate  Дата народження не може бути в майбутньому

# birthDate=1850-01-01 (занадто давно)
$ curl -s -X POST http://localhost:8080/register -d login=client01 -d firstName=Олена -d email=o@example.com -d password=Secret123 -d phone=+380501234567 -d birthDate=1850-01-01 
  HTTP 400
  birthDate  Дата народження не може бути раніше 1900 року

# phone=abc
$ curl -s -X POST http://localhost:8080/register -d login=client01 -d firstName=Олена -d email=o@example.com -d password=Secret123 -d phone=abc -d birthDate=1998-04-12 
  HTTP 400
  phone      Телефон: необов'язковий + і від 10 до 15 цифр, без пробілів

# email=a@b (без крапки в домені)
$ curl -s -X POST http://localhost:8080/register -d login=client01 -d firstName=Олена -d email=a@b -d password=Secret123 -d phone=+380501234567 -d birthDate=1998-04-12 
  HTTP 400
  email      E-mail має містити @ та доменне ім'я, наприклад name@example.com

# Нульовий байт у логіні (%00): передаємо вже закодованим, щоб оболонка його не відкинула
$ curl -s -X POST http://localhost:8080/register -d 'login=client%00x&firstName=Олена&email=o@example.com&...'
  HTTP 400
  login      Логін може містити лише латинські літери, цифри та символи _ . -

# Повторюваний параметр firstName=a&firstName=b (parameter pollution)
$ curl -s -X POST http://localhost:8080/register -d 'login=client01&firstName=Anna&firstName=Maria&email=o@example.com&...'
  HTTP 400
  firstName  Ім'я має містити лише літери

# Unicode: RTL-символ U+202E у логіні
$ curl -s -X POST http://localhost:8080/register -d login=client‮01 -d firstName=Олена -d email=o@example.com -d password=Secret123 -d phone=+380501234567 -d birthDate=1998-04-12 
  HTTP 400
  login      Логін може містити лише латинські літери, цифри та символи _ . -

# Спецсимвол в імені (підкреслення)
$ curl -s -X POST http://localhost:8080/register -d login=client01 -d firstName=Олена_ -d email=o@example.com -d password=Secret123 -d phone=+380501234567 -d birthDate=1998-04-12 
  HTTP 400
  firstName  Ім'я має містити лише літери

# Unicode: цифри й дефіс в імені (не літери)
$ curl -s -X POST http://localhost:8080/register -d login=client01 -d firstName=Anna-Maria -d email=o@example.com -d password=Secret123 -d phone=+380501234567 -d birthDate=1998-04-12 
  HTTP 400
  firstName  Ім'я має містити лише літери

# Пароль із кирилиці довший за 72 байти
$ curl -s -X POST http://localhost:8080/register -d login=client01 -d firstName=Олена -d email=o@example.com -d password=Ж1жжжжжжжжжжжжжжжжжжжжжжжжжжжжжжжжжжжжжжжж -d phone=+380501234567 -d birthDate=1998-04-12
