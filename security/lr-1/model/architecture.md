# Опис архітектури «Прокат автомобілів»

## Елементи

| ID | Тип | Назва | Опис і властивості |
|--|-----|-------|---------------------------|
| EI-1 | Зовнішній учасник | Клієнт (орендар) | Людина з браузером або мобільним браузером; до входу не автентифікована, пристрій не контролюється сервісом. |
| EI-2 | Зовнішній учасник | Менеджер парку | Співробітник прокату; керує автопарком, цінами й бронюваннями лише через адмін-панель. |
| EI-3 | Зовнішній учасник | Платіжний шлюз | Зовнішній провайдер: hosted payment page і webhook. Картка вводиться на його сторінці, PAN до сервісу не потрапляє. (поза межами аналізу; Сторонній провайдер: безпека його інфраструктури покривається договором і SLA.) |
| EI-4 | Зовнішній учасник | Email/SMS-провайдер | Зовнішній сервіс для підтвердження пошти/телефону й нагадувань про повернення авто. |
| EI-5 | Зовнішній учасник | Геокодинг API | Зовнішній картографічний сервіс: адреси видачі й повернення авто, відстань. |
| P-1 | Процес | Веб-клієнт | Інтерфейс у браузері (SSR + невеликий JS): форми реєстрації, пошуку авто, бронювання; клієнтська валідація лише для зручності. (вебзастосунок; привілеї: користувач (браузер)) |
| P-2 | Процес | Reverse proxy WAF | nginx: термінація TLS, обмеження частоти й розміру запитів, заголовки безпеки. (привілеї: мережевий периметр) |
| P-3 | Процес | Backend API | Spring Boot: автентифікація, сесії, каталог, бронювання, ролі, валідація вводу. (вебзастосунок; привілеї: службовий обліковий запис застосунку) |
| P-4 | Процес | Адмін-панель | Окремий вебклієнт на окремому origin; доступ лише з мережі персоналу (VPN/allowlist) і з MFA. (вебзастосунок; привілеї: адміністратор) |
| P-5 | Процес | Платіжний модуль | Створює платіжну сесію, приймає webhook шлюзу, перевіряє HMAC-підпис, оновлює статус платежу. (картки: лише через сторінку шлюзу; привілеї: службовий обліковий запис платежів) |
| P-6 | Процес | Воркер сповіщень | Фоновий процес із черги: надсилає email/SMS-повідомлення. (привілеї: службовий обліковий запис воркера) |
| DS-1 | Сховище даних | Реляційна БД | MySQL/PostgreSQL: користувачі (BCrypt-хеші), авто, бронювання, платежі (токен і статус), аудит. (зберігає облікові дані; шифрування) |
| DS-2 | Сховище даних | Файлове сховище | Об'єктне сховище: фото авто та скани посвідчень водія (чутливі дані). (шифрування) |
| DS-3 | Сховище даних | Кеш і сесії (Redis) | Серверні сесії та лічильники rate limit. (зберігає облікові дані) |
| DS-4 | Сховище даних | Журнали | Журнали застосунку й подій безпеки (без паролів і PII). (журнал) |

## Межі довіри

| Межа | Назва |
|---|-----------------|
| TB-A | Інтернет (публічна, недовірена зона) |
| TB-B | DMZ |
| TB-C | Внутрішня мережа застосунку (приватна) |
| TB-D | Зона даних (приватна) |
| TB-E | Привілейована зона персоналу (VPN, allowlist) |
| TB-F | Треті сторони (поза нашим контролем) |

## Потоки даних

| ID | Напрямок | Дані | Протокол і захист |
|--|-------|-----------|-----------|
| F1 | з EI-1 до P-1 | Логін, ПІБ, пошта, пароль, телефон, дата народження, дати оренди. | UI |
| F2 | з P-1 до P-2 | Запити браузера до сервісу. | HTTPS (TLS 1.2/1.3, HSTS) |
| F3 | з P-2 до P-3 | Перенаправлені запити. | HTTP/mTLS у внутрішній мережі |
| F4 | між P-3 і DS-1 | SQL-запити: облікові дані, бронювання. | JDBC + TLS, параметризовані запити |
| F5 | між P-3 і DS-3 | Сесії та лічильники rate limit. | Redis AUTH + TLS |
| F6 | між P-3 і DS-2 | Фото авто, скани посвідчень. | S3-подібний API, pre-signed URL |
| F7 | з P-3 до P-5 | Ідентифікатор бронювання, сума. | внутрішній виклик |
| F8 | між P-5 і EI-3 | Створення платіжної сесії, redirect-URL, статус. | HTTPS, API-ключ |
| F9 | з EI-1 до EI-3 | Дані картки (поза нашим периметром). | HTTPS (сторінка шлюзу) |
| F10 | з EI-3 до P-5 | Подія «оплачено/відхилено». | HTTPS, HMAC-підпис, ідемпотентність |
| F11 | з P-5 до DS-1 | Статус платежу, токен. | JDBC + TLS |
| F12 | з P-3 до P-6 | Подія для надсилання листа/SMS. | черга |
| F13 | з P-6 до EI-4 | Листи й SMS. | HTTPS, API-ключ |
| F14 | між P-3 і EI-5 | Адреси й координати. | HTTPS, API-ключ |
| F15 | з EI-2 до P-4 | Вхід менеджера, керування парком і цінами. | HTTPS + MFA |
| F16 | з P-4 до P-3 | Адмін-запити. | HTTPS, роль ADMIN |
| F17 | з P-3 до DS-4 | Події безпеки й помилки без PII і паролів (також від P-2). | syslog/файл |
| F18 | з P-3 до P-1 | HTML/JSON, Set-Cookie. | HTTPS |
