# Протокол прогонів: сирі результати

Дата прогонів 2026-11-17. Комп'ютер: ноутбук, 16 потоків, Linux, домашня мережа. Браузер: Chromium 156.0.8078.4 у docker-образі `lr-shots:pw1.64.1` (Playwright 1.64.1 для Python). Застосунок на живому хостингу: https://emobility.pages.dev. Файли нічого не редагувалися після прогону. Окремо `phone.md` містить записи прогонів на смартфоні 2026-11-18.

| Файл | Що містить | Як отримано |
|---|---|---|
| `checks.txt` | вивід 32 автоматичних сценаріїв, перевірка запитів поза дозволеними, помилок консолі, підсумок | `digital_tech/prototype/tests/run.sh checks.py` (локальна копія застосунку, мережа лише для сторінки, скрипта Telegram і плиток) |
| `webhook.txt` | коди відповіді вебхука (POST без секрету, POST з хибним секретом, GET), перенаправлення HTTP на HTTPS, версія TLS, заголовки | `curl` до живого адреса, без запитів, які змушують бота надсилати повідомлення |
| `secrets-scan.txt` | пошук рядка виду токена бота в репозиторії та у файлах, отриманих з живого адреса | `git grep --untracked -E` і `grep -rn -E` за шаблоном `[0-9]{8,10}:[A-Za-z0-9_-]{30,}` |
| `live-hashes.txt` | SHA-256 кожного файлу теки `app` у репозиторії та на живому адресі | `curl` кожного файлу, `sha256sum` |
| `measure.json` | 5 прогонів часу відкриття карти (повторний і перший запуск дня), часу від карти до поїздки та кількості дотиків | скрипт `measure.py` з тим самим образом, на живому адресі, 17.11 приблизно о 18:10; дотики скриптові |
| `phone.md` | сирі записи прогонів на смартфоні 18.11: п'ять запусків секундоміром (U3, U2), прохід M2 у Telegram на Android, прохід A3 з TalkBack і два дефекти фокусу | вручну на Samsung Galaxy A54 5G, Android 14, Telegram 10.14.1, 4G |
