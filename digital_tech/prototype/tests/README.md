# Автоматичні перевірки прототипу

`checks.py` запускає 31 сценарій у Chromium (Playwright 1.64.1 для Python) і виводить PASS або FAIL для кожного, потім три підсумкові рядки: запити поза дозволеними, помилки консолі, кількість PASS. Код завершення 0 лише коли все пройшло. Сценарії відповідають таблиці 4 ТЗ; їхній перелік є в додатку Д пояснювальної записки.

Запуск з теки `digital_tech/prototype/tests`:

```
./run.sh checks.py
```

Потрібні Docker і образ `lr-shots:pw1.64.1` (Python, Playwright 1.64.1, Chromium). Застосунок `../app` віддає локальний `python -m http.server` на порту 8099, сторінки не змінюються. Мережа дозволена лише для сторінки, скрипта Telegram і плиток OpenStreetMap, будь-який інший запит дає FAIL.

- `common.py` містить сервер, перехоплення запитів і синтетичну плитку карти.
- `fonts.conf` підставляє шрифт Adwaita Sans для кирилиці в знімках, якщо він є на хості.
- `har/` (кеш плиток і скрипт Telegram) не входить до репозиторію: за його відсутності скрипт Telegram завантажується один раз, а відсутні плитки замінюються синтетичними без мережі.
